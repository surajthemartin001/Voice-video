# Everything at a Glance - Audio Lip-Sync Assistant

ऑडियो फ़ाइल अपलोड करके रियलिस्टिक लिप-सिंक (Lip-Sync) एनिमेशन, वॉइस मॉर्फिंग (तोता, बच्चा, बुजुर्ग, रोबोट, स्टूडियो) और स्क्रीन रिकॉर्डिंग के साथ वीडियो डाउनलोड करने का संपूर्ण टूल।

---

## 🚀 GitHub Pages पर लाइव डिप्लॉय करने का तरीका (Fix for White Screen)

Vite प्रोजेक्ट्स में GitHub Pages पर डिप्लॉय करने पर **सफेद स्क्रीन (White Screen)** आने का मुख्य कारण एसेट्स का गलत पाथ (`/assets/` की जगह `./assets/`) और Jekyll ब्लॉकिंग होता है।

इस प्रोजेक्ट में इसे पूरी तरह से फ़िक्स कर दिया गया है:
1. `vite.config.ts` में `base: './'` सेट किया गया है ताकि किसी भी GitHub Repository सब-फ़ोल्डर में CSS/JS सही लोड हों।
2. `public/.nojekyll` फ़ाइल जोड़ी गई है ताकि GitHub Pages किसी भी फ़ाइल को अनदेखा न करे।
3. `dist/404.html` ऑटो-जनरेट होता है ताकि रिफ्रेश करने पर पेज न टूटे।
4. `.github/workflows/deploy.yml` ऑटोमेटेड GitHub Actions वर्कफ़्लो शामिल है।

### विकल्प 1: GitHub Actions द्वारा स्वचालित डिप्लॉय (Recommended)
1. अपने कोड को GitHub पर पुश करें:
   ```bash
   git add .
   git commit -m "Fix GitHub Pages deployment and base path"
   git push origin main
   ```
2. अपने GitHub रिपॉजिटरी में जाएँ।
3. **Settings** -> **Pages** (बायें मेनू में) पर क्लिक करें।
4. **Build and deployment** -> **Source** में ड्रॉपडाउन से **GitHub Actions** चुनें।
5. बस! कुछ ही सेकंड में GitHub Actions अपने आप बिल्ड बनाकर आपकी साइट को लाइव कर देगा (`https://<username>.github.io/<repo-name>/`)।

---

### विकल्प 2: बिल्ड फ़ोल्डर (`dist`) से डिप्लॉय करना
अगर आप मैन्युअल रूप से `gh-pages` ब्रांच या `/dist` से होस्ट करना चाहते हैं:
1. बिल्ड बनाएँ:
   ```bash
   npm run build
   ```
2. `dist` फ़ोल्डर की सभी फ़ाइलों को अपनी `gh-pages` ब्रांच में डालें।
3. **Settings** -> **Pages** में जाकर Source: **Deploy from a branch** और Branch: **gh-pages** चुनें।

## 🛠️ मुख्य विशेषताएँ (Features)
- 🎵 **कस्टम ऑडियो अपलोड**: कोई भी MP3, WAV, AAC, M4A फ़ाइल अपलोड करें।
- 🦜 **वॉइस टोन / पिच मॉर्फिंग**:
  - 🦜 **तोता (Parrot)**: हाई पिच और क्रिस्प बर्ड टोन
  - 👶 **बच्चा (Child)**: क्यूट हाई-पिच चिल्ड्रन्स वॉइस
  - 👴 **बुजुर्ग (Elder)**: डीप, वार्म और गंभीर आवाज
  - 🤖 **रोबोट (Robot)**: मैटेलिक सिंथेसाइज़र टोन
  - 📢 **स्टूडियो (Studio)**: ब्रॉडकास्ट क्लैरिटी वॉइस
  - ✨ **ओरिजिनल (Original)**: नेचुरल अनटच्ड वॉइस
- 🎚️ **मैन्युअल कंट्रोल्स**:
  - पिच शिफ्टर (-12 से +12 सेमीटोन)
  - ब्राइटनेस / टोन बूस्ट (-8dB से +8dB)
  - मास्टर वॉल्यूम (0% से 150%)
  - प्लेबैक स्पीड (0.8x से 1.3x)
- 👄 **ऑडियो एनालाइज़र लिप-सिंक**: वेब ऑडियो API द्वारा रीयल-टाइम फ्रीक्वेंसी और वॉल्यूम डिटेक्ट करके सटीक मुंह की मूवमेंट और आंखों की ब्लिंकिंग।
- 🎥 **स्क्रीन व ऑडियो रिकॉर्डिंग**: 60fps स्मूथ वीडियो सीधे गैलरी में सेव करने की सुविधा (`.webm` / `.mp4`)।
- 🟩 **ग्रीन स्क्रीन मोड**: वीडियो एडिटिंग (CapCut, Premiere, DaVinci) में क्रोमा की (Chroma Key) हटाने के लिए।
- 🛡️ **रिएक्ट एरर बाउंड्री**: किसी भी अप्रत्याशित समस्या में वाइट स्क्रीन की जगह रिकवरी स्क्रीन।
